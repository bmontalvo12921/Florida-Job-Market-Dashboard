Florida Job Market Dashboard

About the Project

Florida Job Market Dashboard is a Spring Boot web application for viewing job-market information collected by the Florida Job Market Monitor. It is intended to display job postings, salary information, charts, and filters.

Technologies

Java

Spring Boot

MySQL

Maven

Railway

IntelliJ IDEA

Requirements

A compatible Java Development Kit

Maven

MySQL Server

Access to a database containing the job-market tables

Installation

Clone the repository:

git clone https://github.com/bmontalvo12921/Florida-Job-Market-Dashboard.git
cd Florida-Job-Market-Dashboard

Open the project in IntelliJ IDEA or another Java IDE.

Configure the Database

For local development, create a local MySQL database and user. The database must contain the tables and columns expected by the dashboard.

Configure the application to use your local database connection. If the application uses Spring datasource environment variables, set:

SPRING_DATASOURCE_URL

SPRING_DATASOURCE_USERNAME

SPRING_DATASOURCE_PASSWORD

For example, a local JDBC URL may look like:

jdbc:mysql://localhost:3306/job_market

Use the database name, username, and password you created on your own computer. Confirm the actual configuration in the project's application.properties or application.yml before running the application.

Run Locally

Build the project:

mvn clean package

Run the application using the main class in the project or the JAR produced by the build.

java -jar target/<actual-jar-name>.jar

Replace <actual-jar-name>.jar with the filename generated by Maven.

Open the local address and port configured by the application to view the dashboard.

Using Railway

The project has also been configured for deployment to Railway. To deploy it, configure the dashboard's database connection using Railway's MySQL service variables and make sure the application listens on the port expected by Railway.

Check the deployment logs if the application starts but cannot load data. A database authentication error usually means the connection URL, username, password, or database permissions need to be checked.

Getting the Database

The dashboard requires a compatible MySQL database with the expected schema and data.

For local development, developers can create a local database and import a sanitized SQL backup, or run the collector to populate their own database. A CSV export can be used to review the data, but it is not the same as a complete database backup.

Do not share production database passwords or API credentials.
